# goit-js-hw-02

A small JavaScript homework repository for GoIT practice. This project contains four task files that implement basic JavaScript functions and log sample results to the console.

## Project structure

- `index.html` — main HTML page for the project.
- `js/task-1.js` — transaction cost calculation and customer funds validation.
- `js/task-2.js` — string trimming with maximum length and ellipsis.
- `js/task-3.js` — spam detection for messages.
- `js/task-4.js` — delivery cost lookup by country.
- `.gitignore` — files excluded from version control.
- `prettierc.json` — code formatting rules for Prettier.

## How to use

1. Open `index.html` in your browser.
2. Open the browser console to see the output from the JavaScript task files.

Alternatively, run the JavaScript files directly using Node.js:

```bash
node js/task-1.js
node js/task-2.js
node js/task-3.js
node js/task-4.js
```

## Notes

- Each task file defines a single function and logs multiple test cases for demonstration.
- This repository is intended for learning and practicing basic JavaScript control flow and string operations.
